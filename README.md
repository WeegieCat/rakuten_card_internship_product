# 楽天カードアプリ 画面設計デモ（Rakuten-AI Workshop 2026）

インターン課題「要件定義」の成果物として作成した画面設計のHTMLデモです。
実データは含まれておらず、表示されている氏名・金額・カード番号などはすべて架空のサンプルです。

## 画面
| ファイル | 画面 |
|---|---|
| `top.html` | TOP |
| `detail.html` | 明細 |
| `budget.html` | 家計簿 |
| `campaign.html` | 特典（キャンペーン一覧） |
| `profile.html` | 登録情報 |
| `security.html` | セキュリティ（登録情報の第2階層） |
| `recap.html` | 月次ふりかえり |

`assets/data.js` が全画面共通のデータ源です。数値を変えると全画面の表示が同時に変わります。

## 見かた
スマートフォンでの閲覧を想定しています。PCの場合はブラウザを縦長に細くすると実機に近い表示になります。
